# 온에어 호출대기

식당 번호 호출 · 줄 서기 · 손님 휴대폰 알림 · TV 번호판. 가게마다 설정 파일 하나.

## 주소 (`<코드>` = 가게코드)
- 직원 화면: `?s=<코드>`
- 입구 태블릿 (오늘의 QR): `?s=<코드>&door`
- 손님 줄 서기: `?s=<코드>&q&t=<오늘 코드>` (입구 화면 QR에만 들어 있음, 매일 자정에 바뀜)
- 손님 번호로 기다리기: `?s=<코드>&n=15`
- TV 번호판: `?s=<코드>&board`
- QR 안내판 인쇄 (A5): `?s=<코드>&sign`

## 매장 설치 순서
1. **직원 기기**에서 `?s=<코드>` 열기 → ⚙ 설정 → **🔑 열쇠 만들기** (열쇠는 이 기기에만 저장, 저장소에 없음).
2. **입구 태블릿**: 직원 화면 **🔗 기기 연결** → '입구 태블릿' QR을 태블릿 카메라로 찍기 → 입구 화면이 열림 → ⛶ 전체 화면.
3. **TV 번호판**: 같은 창에서 'TV 번호판' QR 찍기 (같은 PC 다른 창이면 🖥 번호판 버튼만 누르면 됨).
4. 두 번째 직원 기기도 '다른 직원 기기' QR로 연결. 카운터에는 종이 안내판(🪧, QR 없음)을 둠.
5. 열쇠를 바꾸면(⚙ 열쇠 바꾸기) 2~4를 다시 해야 함. 기기 연결 QR은 비밀 열쇠이니 손님에게 보이지 않게.

## 새 가게 추가
1. 길고 무작위인 가게코드 만들기 (영소문자·숫자 16~40자).
2. `shops/<코드>.json` 복사해서 이름·색·멘트·`expires`(YYYY-MM-DD) 고치기.
3. 고칠 때마다 `sw.js` 의 `CACHE` 번호 올리기.

## 설정 한 곳 (`app.js` 맨 위)
- `DEFAULT_RELAY` 중계 서버 (지금 ntfy.sh 무료) · `SUPPORT` 연장 문의 연락처 · `GRACE_DAYS` 유예 일수.
- 구독 확인은 `checkSubscription()` 하나 — 나중에 서버 확인으로 바꿀 때 여기만.

## 시험
`node tests/e2e.js` (가짜 중계) · `node tests/e2e.js --real` (실제 ntfy.sh 2건 추가)
· `node tests/count.js` (한 팀당 중계 건수 세기, 가짜 중계) · QR 다시 읽기는 파이썬 OpenCV(`tests/qr_decode.py`) 사용

## 중계 아껴 쓰기
호출은 바로, 대기 등록 번호는 4초 모아서, 입장·노쇼·취소·직접 등록은 따로 안 보내고 다음 방송에 묻어 감. 손님 '확인했어요'는 다시 방송 안 함.
